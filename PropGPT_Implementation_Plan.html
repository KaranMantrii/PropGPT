HYDERABAD PROPERTY PRICE PREDICTION PLATFORM
PropGPT — Comprehensive Implementation Plan
Architectural blueprint and technical specification for building a production-quality, responsive React frontend integrated with an LLM conversational orchestrator and three independent R Plumber machine learning prediction models.
Focus City: Hyderabad, Telangana, India
Frontend: React 18 + Vite + Tailwind CSS
ML Engine: R Plumber (Port :8000)
LLM Backend: Ollama (Llama 3.1 8B)
Version: 1.0.0

1 Executive Summary & System Architecture

PropGPT combines a cinematic real-estate aesthetic with conversational AI and trained statistical/machine learning models. Users can interact via two complementary paths: a ChatGPT-inspired conversational interface with slot-filling extraction, and a structured manual prediction form for deterministic property valuation.

R Plumber ML API (:8000)

  • • POST /predict/flat

Architectural Boundary Guarantee: The React frontend does not call the R Plumber prediction endpoints directly from the LLM conversation flow. The orchestration backend strictly validates the extracted JSON payload before invoking Plumber, preventing invalid requests or hallucinated prediction figures. The manual form calls Plumber through a centralized API service layer.

5 Conversational AI & Backend API Integration

Conversational AI Flow

  1. User Query: User types natural-language inquiry (e.g. "I want to buy a 3 BHK flat in Kokapet around 1800 sq ft") or clicks a suggested prompt card.
  2. Intent Extraction: LLM orchestrator recognizes FLAT_PURCHASE intent and extracts slots: { locality: "Kokapet", bhk: 3, area: 1800 }.
  3. Slot Validation & Follow-up: If required fields are missing (e.g. furnishing), the LLM queries the user interactively.
  4. Execution: Once all required attributes are gathered, the orchestrator issues a POST request to R Plumber.
  5. Structured Response: The prediction returned by Plumber is rendered using the custom PredictionCard inside the chat stream.

R Plumber API Contracts

Endpoint Method Payload Schema (JSON) Sample Response
/predict/flat POST { area, bhk, locality, furnishing, transaction_type, area_source, bathrooms, balconies } { "predicted_price": 18500000, "status": "success" }
/predict/house POST { area, bhk, locality, furnishing, transaction_type, area_source, bathrooms, balconies, ownership, facing, property_floor, total_floors } { "predicted_price": 34000000, "status": "success" }
/predict/rent POST { area, bhk, locality, furnishing, area_source, bathrooms, balconies, property_floor, total_floors } { "predicted_rent": 42000, "status": "success" }
/health GET None { "status": "healthy", "models_loaded": 3 }

Prediction Result Card Specification

Every prediction result (whether via Chat or Manual Form) is presented with high-trust financial formatting:

  • Indian Numbering Format: Values $\ge 1\text{ Crore}$ are formatted as ₹ X.XX Cr; values $\ge 1\text{ Lakh}$ as ₹ XX.X Lakh; rent as ₹ XX,XXX / month.
  • Calculated Price Per Sq.Ft: Calculated deterministically as price / area (e.g., ₹ 10,277 / sq.ft).
  • Property Specifications Pill Bar: Badges for Locality, BHK, Area, Floor, and Furnishing status.
Mandatory Statutory Disclaimer:
"PropGPT provides machine learning-based estimates for informational purposes. These estimates are not certified property valuations or guaranteed market prices."
